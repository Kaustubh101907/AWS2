### ☁️ What is this Service?

This section explores the **Default VPC**. Every time you create an AWS account, AWS automatically builds a "starter" network in every region so you can launch servers immediately without having to configure complex networking rules.

---

### 📝 The Breakdown

Here is everything mentioned in your transcript, simplified into one easy-to-understand paragraph:

For this exercise, the instructor uses the North California region (US-West-1) because it only has two Availability Zones, making it much easier to learn the concepts compared to larger regions. Every AWS region comes with a **Default VPC** (which always uses the CIDR block `172.31.0.0/16`), and you are warned *never* to delete it because you cannot manually recreate a "Default" VPC yourself; if you delete it, you have to beg AWS Support to restore it! Inside this default network, AWS automatically creates one subnet per Availability Zone, and they are all automatically configured as Public Subnets. (A quick networking rule: AWS always reserves exactly 5 IP addresses in every single subnet for its own internal background tasks, so you can never use those). The golden rule for identifying a subnet type is to check its **Route Table**: look for the entry `0.0.0.0/0` (which means "the entire internet"). If that traffic is being sent to an **Internet Gateway (IGW)**, the subnet is Public. If it is being sent to a **NAT Gateway**, it is Private.

### 🚀 Summary

* **Region:** Start learning in North California (US-West-1) because it only has 2 zones.
* **The Golden Rule:** **NEVER DELETE THE DEFAULT VPC.** Only AWS Support can bring it back.
* **Default Setup:** It comes with the CIDR `172.31.0.0/16` and automatically has one Public Subnet for every Availability Zone in that region.
* **The Minus 5 Rule:** AWS claims 5 IP addresses from every subnet for internal routing and DNS, so you cannot assign them to your EC2 instances.
* **The Interview Question:** How do you know if a subnet is public or private? Check the Route Table. If `0.0.0.0/0` routes to an Internet Gateway, it is public. If it routes to a NAT Gateway, it is private.
